## 死循环

> 死循环这种我在智谱网页版见的还是比较多的，见了好几次了。

解决死循环，首先要检测死循环，检测死循环的四种情况：

- 通用重复检测
- 无进展轮询检测
- ping-pong检测
- 全局熔断器
